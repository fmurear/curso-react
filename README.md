# Curso-react
Curso React de Fernando Herrera

# Comandos
- racf -> para crear el contenido de un componente de manera directa.
- yarn create vite -> Crear app.
- yarn -> instalar paquetería.
- yarn dev -> iniciar server con vite.

# Dependencias
- yarn add prop-types -> Para tipar las propiedades de un functional component.
- yarn add --test jest -> Para los tests en jest
- yarn add -D @types/jest -> Añadir tipado de jest.
